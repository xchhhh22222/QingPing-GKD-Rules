# Necy 李跳跳规则维护库

**主力：李跳跳 2.2；GKD 规则已停止扩展。**

这里维护的是 **李跳跳原生规则 JSON**，不是 GKD JSON5，不能在 GKD 的订阅页面导入。仓库名称暂未更改以保持历史链接；过去的 GKD 文件仍保留在根目录作为备份。

## 直接使用：已有 318 条时怎么做

你已经导入过社区大合集，**先不要再次导入全部基础规则**，避免覆盖你的个性化设置。优先使用只包含 3 个浏览器的补丁：

[浏览器专用补丁 `rules/browser-patch.json`](./rules/browser-patch.json)

进入李跳跳 → 更多 → 右上角 ⋮ → 导入规则，打开上面的 JSON 文件，复制**文件全部内容**粘贴保存。

补丁以李跳跳规则格式 `[{ "应用包名 hash": "{\\\"keywords_append\\\":[...]}" }]` 储存。其中 QQ 浏览器会保留上游原有两条弹窗规则，避免只导入补丁就抹掉这部分功能。**注意**：批量导入可能覆盖这三款 APP 的现有自定义设置，建议先备份。若设置已有大量个人修改，不要直接覆盖，可在李跳跳的单 APP 设置中手动追加关键词。

| APP | Android 包名 | Java hashCode | 方案 |
|---|---|---|---|
| QQ 浏览器 | `com.tencent.mtt` | `-103524201` | 追加“跳过 3 / 跳过3”等倒计时关键词 |
| 荣耀浏览器（百度定制）| `com.hihonor.baidu.browser` | `1291563139` | 追加倒计时关键词 |
| 荣耀新版浏览器 | `com.honor.browser` | `-1283234825` | 追加倒计时关键词，**待设备包名验证** |

这些补丁只是未做真机验证的**候选方案**。如果跳过文字不暴露给无障碍服务，追加关键词也没有效果。没有添加坐标盲点或绕过系统的指令。规则字段参考 [李跳跳规则格式范本](https://github.com/lhj1618GitHub/LiTT/blob/main/%E6%9D%8E%E8%B7%B3%E8%B7%B3%E8%A7%84%E5%88%99-%E6%A0%BC%E5%BC%8F%E8%8C%83%E6%9C%AC.txt)。

## 日常维护流程

1. 只接收问题 APP 的名称、版本、现象和无障碍控件信息，不采集私人消息。
2. 优先添加或修复 **APP 专用** `keywords_append` 或有证据的 `popup_rules`，不用跨 APP 的万能“关闭”规则。
3. 修改补丁和合并版时同时验证 JSON 数组、hash 唯一性和内层 JSON 的可解析性；脚本 `node ltt/scripts/validate.mjs`。
4. 记录实际真机成功/失败后，再升级规则版本；未验证规则明确标为实验。
5. 李跳跳没有 GKD 式的通用自动拉取订阅机制，更新后需重新复制导入相应补丁或手工修改单 APP 设置。

## 安全提示

停用 GKD 无障碍服务，避免与李跳跳抢夺点击。请先在 QQ 浏览器、荣耀浏览器分别冷启动测试。如果不能跳过，最重要的是获取广告页面 **无障碍节点文字、控件 ID 和可点击属性**；普通截图不能判断能否自动点击。账号、支付、授权页面不应添加模糊自动点击规则。
